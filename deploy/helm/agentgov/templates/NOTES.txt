{{- end }}

The bootstrap admin token (keep it for break-glass access; create API keys instead):

  kubectl -n {{ .Release.Namespace }} get secret {{ include "agentgov.secretName" . }} -o jsonpath='{.data.admin-token}' | base64 -d
{{- if and .Values.keycloak.enabled .Values.keycloak.demoUsers }}

Demo users admin, alice and audrey sign in with the password:

  kubectl -n {{ .Release.Namespace }} get secret {{ include "agentgov.secretName" . }} -o jsonpath='{.data.demo-password}' | base64 -d

Turn them off (keycloak.demoUsers=false) before anyone else can reach Keycloak.
